## 📖 프로젝트 개요 (Overview)
본 저장소는 **마이크로파공학 실험** 과정을 통해 수행한 **4가지 핵심 RF 수동 소자(비균등 분배기, 배글리 폴리곤, 기셀 분배기, 링 하이브리드)**의 설계 및 전자기장(EM) 시뮬레이션 프로젝트를 담고 있습니다.

모든 프로젝트는 공통적으로 **이상적인 전송선로(TLIN) $\rightarrow$ 마이크로스트립 라인(MLIN) $\rightarrow$ 실제 물리적 2D 레이아웃(EM)**의 3단계를 거치며 진행되었습니다. 특히, 단순한 수식 계산을 넘어 실제 기판 위에 회로를 구현할 때 발생하는 **기생 성분(Parasitic), 선로 겹침, 길이 오차로 인한 위상 틀어짐 문제를 기하학적 튜닝으로 어떻게 해결했는지**에 대한 깊이 있는 엔지니어링 고찰을 포함합니다.

## 🛠️ 프로젝트 1. 3.5GHz 비균등 전력 분배기 (Unequal Power Divider) - 기말 프로젝트

중심 주파수 3.5GHz에서 입력된 전력을 **66% 대 34%로 비균등하게 분배**하면서도, 두 출력 포트 간의 위상차를 없애고 높은 격리도(Isolation)를 확보하는 특수 설계입니다.

* **🚨 문제점 (Task):** 
  이상적인 TLIN 설계 후 마이크로스트립(MLIN)으로 변환하자, `MTEE`(T자 분기)와 `MBEND`(꺾임) 같은 비이상적 구조물에 의해 기생 성분이 유발되었습니다. 특히, 격리를 위해 삽입한 100$\Omega$ 칩 저항(SMD)의 실제 물리적 크기(길이 1.6mm, 두께 0.8mm) 때문에 전송 선로의 길이가 강제로 연장되어 **두 출력 포트 간의 위상이 크게 틀어지는 치명적인 문제**가 발생했습니다.
* **💡 해결 과정 (Action):**
  1. **물리적 길이 보상 (Phase Matching):** 100$\Omega$ 저항이 차지하는 1.6mm의 공간만큼, 전송 선로 좌측($Z_a, Z_b$)의 물리적 길이를 정확히 1.6mm 깎아내어 위상 지연을 원천적으로 상쇄시켰습니다.
  2. **비대칭 경로 위상 동기화:** 비균등 분배 특성상 위/아래 암(Arm)의 길이가 다르므로, 곡선 벤드인 `Mbenda`를 활용해 기하학적 물리 길이를 100% 일치시켰습니다.
  3. **임피던스 불연속 제거 (`Mtapper`):** 저항(두께 0.8mm)과 $Z_c$ 전송 선로 간의 두께 단차로 인한 반사 손실(Loss)을 막기 위해, 부드럽게 두께를 이어주는 테이퍼링 라인(`Mtapper`)을 삽입하고 전기적 총길이를 재조정했습니다.
* **🏆 최종 결과 (Result):**
  EM 시뮬레이션 결과 중심 주파수 3.5GHz에서 S11, S22, S33, S32 모두 **-25dB 이하**의 완벽한 정합성을 달성했습니다. 출력 전력은 포트 2 **-1.866dB (약 66%)**, 포트 3 **-4.627dB (약 34%)**로 목표치를 정확히 충족했으며, 두 출력 간의 **위상 오차를 $\pm 5^\circ$ 이내**로 완벽하게 억제했습니다.

## 📐 프로젝트 2. 배글리 폴리곤 전력 분배기 (Bagley Polygon Power Divider)

영국 RAE의 Geoffrey C. Bagley가 고안한 구조로, 다중 포트 간 균등한 신호 분배와 정밀한 위상 정렬(In-phase)을 위해 레이더 및 빔포밍 시스템에 쓰이는 다각형 네트워크입니다.

* **🚨 문제점 (Task):** 
  배글리 폴리곤은 이론적으로 완벽한 대칭형 구조(원형 또는 정다각형)를 요구합니다. 완벽한 위상 일치를 위해 '원형(Circular)'으로 구현할 것인가, 아니면 다른 회로와의 결합 및 공간 효율성을 위해 '사각형(Square)'으로 구현할 것인가에 대한 설계 딜레마가 발생했습니다. 사각형으로 구현 시 직각으로 꺾이는 `MTEE`와 `MBEND` 구조가 강제되어 기생 성분이 대거 유입되었습니다.
* **💡 해결 과정 (Action):**
  원형 구조는 위상 정밀도에서 이상적인 $180^\circ$에 근접하지만, 실제 RF 기판 설계 시 낭비되는 공간이 너무 크고 타 모듈과의 결합(T-Junction 등)이 매우 까다롭습니다. 따라서 **제작 편의성과 시스템 통합을 고려하여 사각형 구조를 채택**했습니다. 사각형 변환으로 인해 위상이 $180^\circ$에서 $186^\circ$로 틀어지는 현상을 발견하고, 각 변의 선로 길이를 0.16mm 단위로 미세 튜닝하여 위상 오차를 최소화했습니다.
* **🏆 최종 결과 (Result):**
  입력 1포트에 대해 나머지 3개 포트가 정확히 **-4.7dB**로 3등분 전력 분배됨을 EM 시뮬레이션으로 증명했습니다. 반사 손실(S11)은 **-81.2dB**로 극강의 정합성을 보였으며, 실용적인 사각형 레이아웃으로 설계되었음에도 훌륭한 위상 제어 성능을 확보했습니다.

## 💪 프로젝트 3. 기셀 전력 분배기 (Gysel Power Divider)

윌킨슨(Wilkinson) 분배기가 가진 고출력/방열의 한계(내부 저항이 타버림)를 극복하기 위해, $\lambda/4$ 선로를 연장하여 **외부 접지 저항(External Termination Resistor)**으로 열을 방출할 수 있게 만든 고출력 전력 분배기입니다.

* **🚨 문제점 (Task):** 
  기셀 분배기는 윌킨슨 분배기보다 구조가 훨씬 복잡하고 $\lambda/4$ 라인 수가 많습니다. MLIN(마이크로스트립)으로 2D 레이아웃을 구현하는 과정에서, 왼쪽과 오른쪽 전송 선로의 길이가 미세하게 달라 **선로 간에 물리적인 빈틈(단선)이 생기거나 겹치는 현상**이 발생했습니다. RF에서 선로 단선은 완벽한 개방(OPEN)으로 인식되어 신호가 100% 차단되는 치명적 에러를 낳습니다.
* **💡 해결 과정 (Action):**
  단순히 선로를 늘리면 전체 전기적 길이($\lambda/4$)가 변해버려 위상과 정합이 완전히 붕괴됩니다. 이를 우회하기 위해 **선로의 코너에 곡선형 벤드(`MBENDA`)를 정밀하게 삽입**하여, $\lambda/4$ 전기적 길이를 1%의 오차도 없이 유지하면서도 물리적으로 끊어진 왼쪽과 오른쪽 선로를 완벽하게 이어붙이는 레이아웃 튜닝을 수행했습니다.
* **🏆 최종 결과 (Result):**
  수정된 EM 레이아웃 시뮬레이션 결과, 단선 문제를 해결하고 S11, S22, S33 모두 **-29dB 이하**의 훌륭한 정합성을 보였습니다. 고출력 열 분산 구조를 유지하면서도 $\pm 0^\circ$에 가까운 출력 위상 동기화를 달성했습니다.

## 💍 프로젝트 4. 링 하이브리드 커플러 (Rat-Race / Ring Hybrid Coupler)

전체 둘레가 $1.5\lambda$인 원형 링 구조를 통해, 합(Sum, $\Sigma$) 포트와 차(Difference, $\Delta$) 포트 입력에 따라 출력 신호를 동위상($0^\circ$) 또는 역위상($180^\circ$)으로 정확히 쪼개거나 합치는 4포트 네트워크입니다.

* **🚨 문제점 (Task):** 
  이론적 모델(TLIN)에서는 완벽한 50:50 분배(-3dB)와 정확한 위상차($180^\circ$)가 나오지만, 실제 마이크로스트립(MLIN)으로 기판(Er, 두께, 손실 탄젠트) 위에 원형 링을 구현하자 **방사 손실(Radiation Loss)과 커플링 현상**으로 인해 성능이 열화되었습니다.
* **💡 해결 과정 (Action):**
  이론적 전기각 $270^\circ + 3 \times 90^\circ = 540^\circ$를 실제 물리적 기판 스펙에 대입하여 선로 최적화 계산(`LineCalc`)을 수행했습니다. 그 결과 **총 물리적 길이 103.95mm, 링 반지름(r) 16.55mm**의 정확한 치수를 도출해내어 EM 2D 레이아웃으로 구현했습니다. 모서리 반사와 곡률에 따른 임피던스 변화를 고려하여 포트 접합부의 두께를 미세 조정했습니다.
* **🏆 최종 결과 (Result):**
  EM 시뮬레이션 결과, 정합성(S11)은 방사 손실의 영향으로 -32dB 수준으로 아주 약간 떨어졌으나 여전히 매우 훌륭한 수치입니다. $\Sigma$포트 입력 시 출력 간 **$0^\circ$ 동위상 분배(-3.05dB)**를, $\Delta$포트 입력 시 정확히 **$180^\circ$ 위상차 분배**라는 링 하이브리드 고유의 래트레이스(Rat-Race) 특성을 실제 물리적 환경에서도 완벽히 증명했습니다.

## 💡 종합 결론 및 엔지니어링 고찰 (Conclusion)

본 4개의 프로젝트를 관통하며 배운 가장 큰 교훈은 **"이상적인 이론 모델(TLIN)과 실제 물리적 구현(EM) 사이에는 거대한 갭(Gap)이 존재한다"**는 것입니다.

수식에 대입해 얻어낸 선로의 길이는, 실제 기판 위에서 다른 선로와 만나 T-Junction(`MTEE`)을 이루거나 코너를 도는(`MBEND`) 순간 기생 인덕턴스/커패시턴스를 유발해 위상과 임피던스를 무너뜨렸습니다. 또한 칩 저항(SMD)이 차지하는 물리적인 1.6mm의 공간마저도 고주파에서는 엄청난 위상 지연으로 다가왔습니다.

이를 해결하기 위해 **저항 길이만큼 선로를 깎고, 테이퍼(`Mtapper`)로 두께 단차를 부드럽게 잇고, 벤드(`Mbenda`)로 우회하여 물리적 단선을 막으면서 전기적 길이를 유지하는 '극한의 레이아웃 최적화'**를 거쳤습니다. 

이 과정을 통해 단순히 책에 있는 공식으로 회로를 계산하는 수준을 넘어, **공간적 제약과 기생 성분까지 통제하여 '실제로 제작 가능한(Manufacturable)' 고성능 RF 시스템을 설계하는 실무 엔지니어링 감각**을 확실하게 다질 수 있었습니다.
